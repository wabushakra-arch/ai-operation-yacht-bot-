# Sales & Client Management Operations Guide

## Overview
This module helps you manage client inquiries, draft professional communications, and execute sales tasks with confidence.

## Quick Operations

### 1. **Client Inquiry Response**
- Manage initial client inquiries professionally
- Request qualification information
- Set expectations and next steps

**Example Input:**
```
manage enquiries for a 45ft motor yacht, luxury segment
```

### 2. **Buyer Questionnaire**
- Qualify serious buyers
- Gather yacht preferences and budget
- Timeline and decision-making info

**Example Input:**
```
create buyer questionnaire for high-net-worth individual interested in superyachts
```

### 3. **Offer & Counter-Offer Preparation**
- Draft professional offer language
- Counter-offer strategies
- Negotiation talking points

**Example Input:**
```
draft counter-offer response to buyer offering €2.5M for 50ft sailing yacht listed at €3.2M
```

### 4. **Yacht Comparison for Buyers**
- Compare multiple yachts
- Pro/cons analysis
- Market positioning

**Example Input:**
```
compare three 40ft motor yachts: Azimut 40, Sunseeker 40, Fairline 40. Buyer interested in cruising the Mediterranean
```

### 5. **Client Follow-Up Email**
- Professional check-in messages
- Next viewing coordination
- Closing communication

**Example Input:**
```
follow-up email to client after yacht viewing, encouraging purchase decision
```

### 6. **Exclusive Listing Agreement Draft**
- Broker agreement language
- Terms and conditions
- Commission and listing period

**Example Input:**
```
draft exclusive listing agreement for 60ft motor yacht owner selling in the Balearic Islands
```

## Quick Start Example

1. Run the bot:
   ```bash
   python main.py
   ```

2. Select **A** when prompted

3. Provide your request:
   ```
   Draft a professional response to a client interested in a 50ft cruising catamaran, €800k budget
   ```

4. Bot generates ready-to-use email and next-step recommendations

## Tips for Best Results

- **Be specific**: Include yacht type, price range, buyer profile
- **Include context**: Timeline, competing offers, special requirements
- **Mention location**: Mediterranean, Caribbean, local market affects strategy
- **Specify tone**: Professional, friendly, urgent, etc.
